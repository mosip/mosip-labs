# tasks/

Local workspace for running tasks: `tasks/<id>/task-manifest.json`, `evidence/`, `usage.md`, `final-report.md`.
Created by the orchestrator, never committed (see `.gitignore`): records contain local paths, environment names and
approvals. Module onboarding drafts land in `tasks/onboarding-<module>/.crewline/` until they are published to the module.

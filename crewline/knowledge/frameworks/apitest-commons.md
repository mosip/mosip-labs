# apitest-commons

Location: `Api_Automation/mosip-functional-tests/apitest-commons` (artifact `apitest-commons`, 1.5.0-SNAPSHOT as used by apitest-prereg 1.2.1-SNAPSHOT).
Every module depends on it. **Version split (Verified 2026-10-28):** pre-registration resolves 1.5.0-SNAPSHOT from Maven (`~/.m2`), not the local checkout (1.8.0-SNAPSHOT). For static analysis of what a module *runs*, read the resolved `apitest-commons-<version>-sources.jar`; use the checkout only for CoverageCli tooling. **Rebuild it before rebuilding a module after any change.**

| Need | Look in |
|---|---|
| HTTP calls with auth cookie, auto-ID capture | `utils/AdminTestUtil.java` (`postWithBodyAndCookie…`, `writeAutoGeneratedId`) |
| Token per role | `KernelAuthentication.getTokenByRole(role)`; the token travels as cookie `Authorization` |
| Response assertion | `OutputValidationUtil` (JSON-path comparison) |
| Cross-test IDs | `DependencyResolver`, `$ID:` replacement in `AdminTestUtil` (`replaceIdWithAutogeneratedId`) |
| Env health / early stop | `HealthChecker.signalTerminateExecution` → remaining tests `SkipException` |
| Coverage matrix tooling | `coverage/CoverageCli` (`init`, `scaffold`, `sync`, `rollup`, `check`, `refresh-docs`) |
| Matrix doc templates | `src/main/resources/io/mosip/testrig/apirig/coverage/templates/` |

Run CoverageCli (Verified on this machine, offline mode works):

```bash
cd mosip-functional-tests/apitest-commons
mvn -q compile -Dgpg.skip=true -Dmaven.gitcommitid.skip=true
mvn -q org.codehaus.mojo:exec-maven-plugin:3.1.0:java "-Dexec.mainClass=io.mosip.testrig.apirig.coverage.CoverageCli" "-Dexec.args=check --module-root ../../pre-registration/api-test --module-code PREREG"
```

Or via the wrapper: `python -m crewline coverage --commons-dir <commons> --module-root <api-test> --module-code PREREG [--offline]`.

# Server Kubernetes manifests

Apply from the **repo root**. Use `seal-secrets.sh` to generate the sealed secret —
never fill real values into `02-secret.yaml` directly.

> Prefer Helm? [`../../helm/nexus-server`](../../helm/nexus-server/README.md) is a
> values-driven equivalent of everything below (Istio or nginx-ingress routing,
> toggleable monitoring/backup/autoscaling). These raw manifests remain a valid
> alternative and are not going away.

## One-time cluster setup (before first deploy)

```bash
# 1. Install cert-manager (Rancher UI → Apps → cert-manager, or):
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/latest/download/cert-manager.yaml

# 2. Install Sealed Secrets controller
kubectl apply -f https://github.com/bitnami-labs/sealed-secrets/releases/latest/download/controller.yaml

# 3. Apply ClusterIssuer for Let's Encrypt TLS (edit email first)
kubectl apply -f Server/k8s/letsencrypt-prod-clusterissuer.yaml
```

## Apply order

```bash
kubectl apply -f Server/k8s/00-namespace.yaml
kubectl apply -f Server/k8s/01-postgres.yaml

# Seal Server/.env → produces 02-sealed-secret.yaml (gitignored)
bash Server/k8s/seal-secrets.sh
kubectl apply -f Server/k8s/02-sealed-secret.yaml

kubectl apply -f Server/k8s/03-deployment-api.yaml
kubectl apply -f Server/k8s/04-service-api.yaml
kubectl apply -f Server/k8s/05-ingress-api.yaml
kubectl apply -f Server/k8s/06-cronjob.yaml
kubectl apply -f Server/k8s/08-postgres-backup.yaml
kubectl apply -f Server/k8s/09-hpa.yaml
kubectl apply -f Server/k8s/10-monitoring.yaml   # requires Rancher Monitoring

# Last — restore vectors from S3 (~10 min, replaces 4–8 hr re-embed)
kubectl apply -f Server/k8s/07-initial-ingest-job.yaml
kubectl wait --for=condition=complete job/nexus-initial-ingest -n mosip-nexus --timeout=3600s
```

Then deploy the UI: [UI/k8s/README.md](../../UI/k8s/README.md).

## Files

| File | Purpose |
| --- | --- |
| `00-namespace.yaml` | `mosip-nexus` namespace |
| `01-postgres.yaml` | pgvector StatefulSet + PVC (20 GB) |
| `02-secret.yaml` | Template only — never fill with real values |
| `02-sealed-secret.yaml` | Generated by `seal-secrets.sh` — apply this; gitignored |
| `03-deployment-api.yaml` | FastAPI (`nexus-server:v1.0.0`, port 8000) |
| `04-service-api.yaml` | ClusterIP `:8000` |
| `05-ingress-api.yaml` | nginx Ingress + TLS (cert-manager) + `/metrics` block |
| `06-cronjob.yaml` | Nightly `run_update.py`, 6 h deadline, nexus-data PVC (10 GB) |
| `07-initial-ingest-job.yaml` | One-time S3 restore Job (pg_restore from snapshot) |
| `08-postgres-backup.yaml` | Daily pg_dump CronJob, backup PVC (20 GB), 7-day retention |
| `09-hpa.yaml` | HPA: nexus-api 1–4 replicas, CPU 70% / memory 80% |
| `10-monitoring.yaml` | ServiceMonitor + PrometheusRule (6 alert rules) |
| `letsencrypt-prod-clusterissuer.yaml` | Let's Encrypt ClusterIssuer — apply once per cluster |
| `seal-secrets.sh` | Encrypts `Server/.env` → `02-sealed-secret.yaml` via kubeseal |
| `dump-vectors-to-s3.sh` | Engineering: pg_dump → gzip → S3 snapshot upload |
| `postgres-init.sql` | Init SQL used by Compose and the postgres StatefulSet |
